# Ovarian Cancer Classification using EfficientNetB0

This project uses transfer learning with EfficientNetB0 to classify medical images into different cancer categories.

## Features
- Transfer Learning (EfficientNetB0)
- Data Augmentation
- Fine-tuning entire model
- Evaluation using:
  - Accuracy
  - Precision
  - Recall
  - F1 Score
  - Confusion Matrix

## Model
- Base: EfficientNetB0 (pretrained on ImageNet)
- Input size: 224x224
- Optimizer: Adam
- Loss: Sparse Categorical Crossentropy

## How to Run
Run the notebook in Google Colab.
